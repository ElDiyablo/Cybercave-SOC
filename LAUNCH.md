GitHub Pages handles everything automatically. There is no build step, no server to manage, and no credentials to rotate.

**If the site stops updating:**
1. Go to repo → **Actions** tab
2. Check if "pages build and deployment" shows a red X
3. Click the failed run to see the error
4. Fix the issue in the file and commit again
5. Contact SOC Lead if the error is unclear
